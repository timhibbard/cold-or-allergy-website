# Cold or Allergy: marketing site

Static site for the Cold or Allergy iPhone app, served by GitHub Pages at
<https://timhibbard.github.io/cold-or-allergy-website/>.

- `index.html`: landing page (App Store marketing URL)
- `support.html`: App Store **Support URL**
- `privacy.html`: App Store **Privacy Policy URL**

Plain HTML + CSS, no build step. Edit and push to `main`.

## Before launch
- Replace the "Coming soon" button with the official App Store badge and app link.
- Replace `assets/screen-today.png` with final screenshots.
- Review `privacy.html` against the shipped app.
